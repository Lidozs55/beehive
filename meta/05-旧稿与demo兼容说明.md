# 旧轮次材料说明

旧轮次材料不属于 v2 正典，也不属于 v2 写作输入。

## 处理原则

- `正文/` 中的旧稿：只可用于发现曾经尝试过的情节，不可作为语言、事实或动作模板。
- `chapters/写作卡/` 中的旧卡：视为旧轮次派发材料，不可直接修补成 v2 卡。
- `state/summaries-*.md` 中由旧稿回填的条目：不自动视为 v2 事实；迁移前必须重新核对权威设定和作者裁决。
- 终局 demo：只作主题和结局方向参考，不进入早期章节派发材料。

## v2 迁移规则

任何旧材料若要进入 v2，必须经过三步：

1. 说明它要保留的是情节事实、人物关系还是主题效果。
2. 在 bible、characters、作者裁决或新大纲中找到唯一归属。
3. 用新的 v2 卡和正文重新表达，不复制原句和原动作链。

在作者确认删除或隔离范围前，旧材料保留在工作区，但不得被派发工具默认读取。
