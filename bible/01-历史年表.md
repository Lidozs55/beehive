# 历史年表与三套时钟

## 时间口径
R为落地后经过的真实地球年，V为公民日历年。把落地瞬间定义为R0、V0（称“元年起点”），避免序数纪年与经过年数混用。开篇V10、R20。终战发生在R-10；十年迁移/保鲜航行之后落地。因此开篇距终战约30真实年，不是20年。

运行周和冻结周各168小时。V时间只在运行周前进，长期R≈2V；任务经历另记T，不回填公民生日。遗落之星一个当地日约32地球小时；所有任务的“7天/21天”均指地球小时制的168/504小时，不能按当地日乘算。

## 历史
| 时间 | 事实与允许使用的证据 |
|---|---|
| 终战前多年 | 单向虫洞勘测；载体脑、改造人和模拟设施建设。六城和六人测试来自工程组织方案，不足以证明人类已知六神 |
| R-10之前 | 扫描工程的征募与基建早于终战至少一年；非侵入扫描对全体登记公民一次性完成，前后不超过一天，官方口径为备份。未成年人由监护人签代签附录（旧称“二代协议”，不是蜂巢出生二代身份）；签约者不知可迁移，更不知虫洞与蜂巢；扫描过程本身不录入脑状态 |
| R-10 | 核战、南极基地最后七小时。封装与发射程序早已部署，七小时是紧急启动/完成清单，不是现场手工培育一亿个脑；扫描至此早已全部完成，无人带有战争当日的记忆 |
| R-10—R0 | 方舟迁移与保鲜航行；路线与虫洞内部时间只给仪器记录，不给全宇宙统一钟的断言 |
| V0 / R0 | 模拟社会启动；公民日历自扫描日同日起始，一代在医院“灾后苏醒”、醒来即被告知灾难突发。模拟口径的灾难与地球真实核战不是同一事件，日期互不对应。陆沉载体脑接入时公民年龄8岁 |
| V0—V2 | 非符文的筛选与试炼已运作；早期工业机器人外勤，基地内自动化持续保留 |
| V2 | 首批第二/三阶段；单人采集与永久服役叙事形成 |
| V3—V5 | 遗迹样本推动六通道研究；V4初等符文部署，V5虚拟训练技能上线；混合生产转向人类契约者主导外勤 |
| V6 | 蜂后可用的繁育接口；终期试炼的高损耗政策制度化 |
| V7 | 蜂后三符共鸣产生自主男性分裂体；不自动获得第二份统治权限 |
| V8—V9 | 逃逸者互助网络逐渐自称“拾遗会”；此前零散逃逸早已可能，组织成立不等于第一次逃逸 |
| V10春—秋 | 上卷：六场试炼、分流、大学入学；陆沉只取得晋级资格 |
| V10秋—V11秋 | 中卷：约一公民年，真实经过约两年；14次有记录的任务窗口，包括终期考核 |
| V11秋以后约0.5V / 1R | 下卷：前哨、遗迹、独立调查、供能危机、改革试点。终章时间不硬塞回V11年末 |
