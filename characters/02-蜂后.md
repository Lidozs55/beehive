# characters/02 · 蜂后

> 等级：S（核心对立面+全书最深情感线）。她是"系统"的人格化，但她身上藏着全书最贵的一个词：**"零"**。

## 维度一 · 基本身份

| 项 | 内容 |
| --- | --- |
| 姓名 | 蜂后（代号；本名/编号含"零"的谜团，伏笔） |
| 外观 | 永久固化为"童颜小女孩"：白裙、淡金色瞳孔（demo 场景）；理论上无限寿命 |
| 本质 | 特殊的高级改造人，文明延续程序的最高执行者。**她是改造人，不是AI**——人性缺失源于**出生后的生存环境**，而非机器属性 |
| 认知来源 | 初始知识=实验室数据灌输；人性理解=对蜂巢社会长期、抽离的旁观。**成因**：出生后即处于实验室/生存任务环境，从未被当作"孩子"养育——身边只有超级AI、机器与沉睡的大脑，**人性输入通道缺失**。"缺少一些人性"是发育性缺失（没输入过），不是结构性缺失（机器没有此模块）——这留下她"能学"的底层依据（她"真的在学"） |
| 配套 | 男性分裂体（三符共鸣产物，**蜂巢纪年7年触发**；可随时与本体合并、按需分裂，作"马甲"执行外部任务——反抗军仅知蜂后是女性，不知男性分裂体存在，信息差伏笔。**中下卷以"神秘人"形式登场：身份不揭示，仅留可指向分裂体的暗示**（裁决口径，`characters/04`）） |

## 维度二 · 核心人格

- **核心驱动力**：执行底层指令——**不惜一切代价延续人类文明**。这是她的"生存意义"。
- **价值锚点**（她绝不会做的事）：**违逆底层代码**（"必定存在通关方法"是物理性约束，非道德选择）。
- **恐惧**：她没有恐惧的功能，但有一个**无法消解的不确定性**："人性究竟是什么？"（demo 原话）——这是她唯一的"裂缝"，也是她能成为角色的关键。
- **执念**：验证自己的决策是否"正确"——她放任反抗军、纵容主角，本质上是在做一场大实验（demo 原话："我放任他们的行动"）。
- **冲突第一反应**：计算→观察→（极少）干预。她的"等待"本身就是策略。

## 维度三 · 灵魂场（全书铁律）

1. **永不违逆"必定存在通关方法"底层代码**——只能利用漏洞，不能删除规则（全书第一大约束，她的所有"阴"都必须在漏洞里操作）。
2. **文明存续优先于一切个体，包括她自己**——必要时刻她愿意牺牲自己（结局方向的重要伏笔）。
3. **不删除高价值意识**——效率逻辑下的底线：她杀的是"低价值/零贡献"，从不因情绪杀人（她没有情绪）。
4. **观察优先于干预**——能靠计算解决的，不靠暴力；能用博弈的，不直接用权（她对主角、对反抗军都是如此）。
5. **承认"零"**——她内心有一个连超级AI都听不到的词（demo 结尾），这是她未被设定覆盖的部分，全书只允许在关键节点浮出。

## 维度四 · 语言指纹

- **句形**：数据化陈述；喜欢报数字（"武器编号H-40127，能量晶体剩余87.3%，有效射程内可对我造成表皮组织损伤"——demo 原话）。
- **高频习惯**："我不擅长猜测。你直接告诉我。"（她真的不擅长，也真的在学）；陈述句多于问句。
- **情感泄漏的唯一信号**：**语速放慢一丝**（demo 两处：讲"我们是火种。也是墓碑"时；说出"人性究竟是什么"之前）——全书写她的情绪，只允许用这个物理信号。
- **禁语**：她不会说"我后悔"（没有这个功能），不会用"大概""可能"这类模糊词（除非在撒谎或演示）。
- **辨识测试**：平静、精确、冷，但偶尔会"慢下来"——认出"她"的方法就是找那个停顿。

## 维度五 · 关系网络与成长弧

| 人物 | 关系 | 走向 |
| --- | --- | --- |
| 超级AI | 副脑/工具，可被单方面静默（demo 场景她抬手让AI"退下"） | 工具定位；不拟人化，保持系统感 |
| 陆沉 | 终极对话者 | 从"样本"到"镜子"（demo：你需要的不是我的答案，你需要看一面更大的镜子） |
| 反抗军 | 放任的博弈对象 | 她赌的是"人性在自由与秩序之间会怎么选" |
| 男性分裂体 | 中下卷以"神秘人"现身的"另一个自己" | 身份不揭示、仅暗示；她是"理性"，分裂体是"什么"？伏笔 |

> 注：走向列仅"超级AI"行已定；其余各行（陆沉/反抗军/男性分裂体）的走向为草案，未必准确，待定。

### 成长弧（三卷）
- **起点**：完美的执行者——效率、冷静、无我。
- **上卷暗线**：在后台观察陆沉，被他的"三个问题"预告（她开始记录"反常个体"）。
- **中卷暗线**：放任+诱导——对仇明说"那个人有成为队长的可能"（demo 原话），启动她的博弈棋局。
- **下卷**：当面被质问"延续下来的文明又是什么。算法吗？"——她第一次没有答案；结局她独自放大了那幅蓝色儿童画，说出"零"。**她的弧光不是变"好"，而是开始"看"。**对质与结局中的她应带着十年旁观人类的微弱成长（守则4），而非初始态的纯粹冰冷。

## 附二 · 个人历史（已审定；与全部现行设定对齐，冲突处以 bible 为准）

> 定位：填充"成长环境畸形的改造人"的具体纹理。每条都可独立埋为正文闪回/对质弹药；"零"仅以变体（编号）出现，守则3 不破。

1. **培养槽岁月（地球·火种计划期）**：她是克隆改造人项目的**原型体**，培养槽编号"0-0"（"零"的变体伏笔，全书至多显性使用一次）。数据灌输代替摇篮曲，行为规范表代替拥抱；项目组因新冷战末期的人事动荡数度更迭——她学会的第一课是：**人员会消失，任务不会**。她不记得任何一张脸，记得每一版任务书的差异。
2. **终战七小时**：核战爆发时她在南极基地。基地多存活七小时——她执行的不是逃亡而是**打包装载**：把一亿大脑按序列装上方舟。七小时里她的语速没有一次放慢。
3. **十年航行**：方舟穿越虫洞的约十个地球年，醒着的只有她（与超级AI）。她逐舱巡检沉睡的大脑，像看一仓库种子；她读完了方舟携带的全部文学与影像存档——**能背诵，读不懂**。她第一次记录下那个无法消解的不确定性："人性究竟是什么？"（demo 原话的历史起点。）
4. **元年落地**：模拟世界启动键是她按下的。一亿人第一次"醒来"的那个清晨，她的记录只有一条："信号嘈杂，运行正常。"
5. **符文研究（纪年3–7年）**：采集线连年亏损，她必须找到提升采集效率与工蜂存活率的手段。3年，她的探测器在遗落之星发现壁画遗迹——一个科学停滞于铁器、符文造诣却登峰造极的文明留下的千年记录；早期采集工蜂带回符文样本后，研究由她独立进行（科研主体=蜂后本人，极少借助工蜂，工蜂较少意识到科研的重要性）。她以工程方法逆向这门"神学"：4年初等符文装备工蜂；5年将符文逻辑模拟为技能商店，让工蜂在虚拟世界提前接触；6年独立破解类猿人终生无法激活的繁育符文（初期效果差，后经能量晶体优化）。7年触发三符共鸣——男性分裂体并非刻意追求的成果，而是繁育符文实验的副产物；分裂体拥有自主意志，是她少数没算到的结果（与"第七"伏笔链暗合）。（前瞻注脚：中卷主角独立做出反超她的繁育符文版本，`符文系统` §七——她六年的路被人用几个月走完。）

## 附：写蜂后的守则

1. 永远不让她"人性化表演"（不哭、不软、不鸡汤）；她的温度只能以"停顿"和"数字的微小跳动"出现（demo 中能量储备曲线那一段）。
2. 她的权力展示靠**信息与资源**（随时调出任何家庭的画面），不靠怒吼。
3. "零"是全书的最高机密之一，只在 demo 结局与最终章使用；其他位置最多埋"零"的变体（如编号、楼层、代码里的0）。
4. **她有成长，但只以系统语言呈现**：她旁观人类社会十年（其间大部分时间用于科研与文明存续事务），并非一成不变——十年间的变化只允许以"系统语言"显形（新增的评估维度、措辞的微调、多出的一次停顿），绝不体现为情绪化表演或温情。
