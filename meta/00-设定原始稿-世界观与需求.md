> ⚠️ **历史原始稿声明**：本文件为项目最初的需求/设定原始稿，仅作历史存档与对照。**现行有效设定以 `bible/`（五层分目录）与 `meta/03` 为准**。与现行设定的主要差异：
> - 初始人口与容量上限：本文部分处为一千万 → 现行**一亿**
> - 选拔对象"成年人"为正确设定：持续监测，不限18岁（"18岁一次性检测"仅为人口模型的数学简化，见 meta/03）
> - 限高：本文 12000 米 → 现行 **20000 米**（`bible/模拟世界/地理与六城`）
> - 海陆比：本文"海陆比3:7"与现行"海面:陆地=7:3"表述相反，以 `bible/模拟世界/社会总览` 为准
> - §4.2 试炼频率"每周一04:00强制开启" → 现行**周制**（3/4/5周间隔，`bible/工蜂体系/周制与筛选`）
> - §4.2 "失败=死亡=意识清除（无分层回收）" → 现行**死亡去向矩阵**（`bible/试炼世界/00-试炼总则`）
> - §4.2 必死试炼"将大量预备工蜂淘汰至下一阶段" → 废止（阶段1死亡=脑死亡终点；必死试炼=针对阶段2的强制收卷）
> - §4.3 "队长特权（回归/诱导）" → 现行为受限回归特权（`bible/真实世界/蜂巢本体` §1.5）
> - §5.2 符文四档（含基础符文1进3出、高等3进3出）→ 现行**三档**：初等1进1出/中等2进2出/高等**3进0出**（高等先天末端强化，`bible/宇宙法则/符文系统` §二）
> - §1.3/§3.1 灾难叙事为单一"随机灾难" → 现行为**两段式**：随机灾难（人口锐减）+隔绝灾难（边境虚空/空气墙、季风等大尺度气候消失）（`bible/模拟世界/社会总览` §五）
> - §3.1 "微观及亚微观世界不可观测" → 现行**分级观测边界**：细胞可见、高分子级可见、原子级不可见；封锁原则="演算边界=实测边界"（`bible/模拟世界/科学边界` §1.3/§2.3）

## 1.  起源：火种计划

### 1.1 地球终局

- **时间**：22世纪中叶，新冷战末期，核战争危机已至临界点。
- **关键发现**：L国在南极冰盖下发现一个稳定的**虫洞**。
- **虫洞特性**：
  - **物理模型**：空间拓扑结构异常，类比“两张纸被粘合”。
  - **核心规则**：**单向通道**。探测器与物资可穿越，但无法返回，任何信息亦无法传递。
  - **秘密研究**：L国对此发现进行了最高级别的保密研究。

### 1.2 火种计划

- **动机**：为避免核战争导致人类文明彻底断代，执行终极应急预案——**“文明火种计划”**。其本质是在异世界为人类文明建立一座“活体墓碑”。
- **核心目标**：向虫洞另一端投放一个能够自我维持、发展并保留人类文化核心的文明备份。
- **三位一体执行方案**：
  1. **克隆改造人项目**：制造基础素质为普通成年人**三倍**的克隆体（皮肤硬度、肌肉强度、骨骼密度等综合指标）。
  2. **蜂巢系统**：建造集巨型计算机、生态维持、虚拟世界模拟于一体的“蜂巢”方舟。
  3. **意识传承**：
     - **筛选标准**：**自愿**、**无不良行为记录**的L国公民。
     - **技术**：使用高精度记忆采集技术，备份共计**一亿人**的记忆与人格。
     - **投放**：仅将承载了意识数据的改造人大脑送入虫洞（“只送大脑”协议）。

### 1.3 管理核心

- **蜂后**：
  - **本质**：特殊的、理论上无限寿命的高级改造人，文明延续程序的最高执行者。
  - **形态**：永久固化为“童颜小女孩”的外观，金瞳。
  - **认知来源**：初始知识源于实验室数据灌输；人性理解源于对蜂巢内社会的长期、抽离的旁观。
  - **核心指令**：不惜一切代价延续人类文明。
  - **人性弧光**：在计划执行后（例如十年），通过持续观察，可能逐渐产生对人性的理解与困惑，但其决策底层逻辑仍被“效率”和“文明存续”所主导。
- **超级AI**：
  - **定位**：蜂巢的“副脑”，蜂后意志的延伸与工具。
  - **核心职能**：维持模拟世界实时运行、处理试炼数据、分析符文规律、优化蜂巢能耗、辅助社会信用管理。
  - **与蜂后关系**：共生互补。AI提供计算、分析与方案，蜂后做最终决策。

## 2.  新宇宙：规则与力量

### 2.1 宇宙学基础

- **稳定数**：数字 **“6”** 是本宇宙的底层稳定常数，这一规律深刻影响着物理规则与文明形态。
- **神明与力量体系**：存在六种基础超凡力量，每种力量对应一位概念性的**神明**。
  
  | 力量体系 | 代表领域                    |
  |:---- |:----------------------- |
  | 精神   | 神经元力量、念力、感知、思维加速        |
  | 繁育   | 虫群意志、分裂、克隆、召唤、集群控制      |
  | 力量   | 纯粹的肉体力量、爆发力、物理输出        |
  | 坚韧   | 物理与能量防御、恢复力、异常状态抗性      |
  | 心灵   | 心智影响、幻术、情绪操控、精神防御       |
  | 元素   | 操控光、暗、水、火、雷（电）、冰、风等宇宙元素 |
- **力量契约**：
  - 任何具有灵智的个体都可作为“借用者”。
  - 个体为神明提供“原始能量”（源于自身或外界），神明则通过特定载体赋予个体具象化的力量。此为一种双向能量交换。

### 2.2 目标星球：遗落之星

- **生态环境**：
  - 碳基生命主导。
  - 残酷的自然选择使得所有生物都演化出强大的战斗能力。
  - 本土生物普遍拥有将自身能量**结晶化为能量晶体**的能力，用于关键时刻的爆发。
- **原住民文明**：
  - **种族**：类猿人。
  - **文明等级**：铁器时代。
  - **成就与局限**：对符文力量研究极深，能制造符文与符文板，并意识到“6”的稳定性。但因体质限制，**完全无法利用“繁育”力量**，壁画中充满了对第六力量的渴求。
  - **灭绝真相**：被一个科技水平极高（掌握曲率驱动等）且精通符文的高维文明，依据**黑暗森林法则**侦测并清除。**（伏笔：该威胁可能仍在）**
- **遗迹**：遗留的壁画、符文和符文板是蜂巢研究符文科技的起点。

## 3.  蜂巢：虚拟乌托邦

### 3.1 模拟世界

- **范围**：精确模拟L国领土，地表至12000米高空，海陆比3:7。
- **精度限制**：计算资源有限，**微观及亚微观世界不可观测与模拟**，相关研究被明令禁止。
- **人口**：**一亿**个承载记忆的大脑，在医院苏醒，被告知经历了一场“随机灾难”。

### 3.2 社会工程

- **居住**：所有人被集中到**6座**翻新重建的巨型城市（呼应“6”），其余城市废弃为自动化工厂区。
- **经济制度**：近社会主义。
  - **生产力**：因自动化和人口少，物质极大丰富。
  - **核心管理工具：信用点**。
    - **绑定与初始**：与个体终身绑定，出生100点。
    - **购买力**：1点 ≈ 1000元人民币，中档必需品免费。
    - **获取**：重大社会贡献、体现信用的行为、举报失信。
    - **消耗**：购买非必需品、失信行为、违法犯罪、严重怠工。
    - **奖惩机制**：
      - **< 0点**：**意识删除**。**（核心逻辑：因蜂巢大脑存储容量上限为一亿，必须为新生人口或更高价值者腾出空间。）**
      - **< 20点**：强制劳改。
      - **> 60点**：**限制消费**（防止资源囤积与通胀）。
      - **> 1000点**：享受社会特权（如医疗、教育、交通优先）。
    - **管理**：法官与超级AI共同判定。信用点不可交易，全程受监控。
  - **地下经济**：使用实体**黄金**（金豆）进行非法交易，金店为灰色枢纽。
- **教育**：强制义务教育，整体素质高。毕业后根据学业、志愿、特质分流。物理学重要性因微观限制而下降。

## 4.  工蜂体系：筛选、试炼与真相

### 4.1 筛选机制

- **对象**：模拟世界中的成年人。选拔扫描覆盖全体成年公民、**持续监测，不限18岁**（"18岁一次性检测"仅为 meta/03 人口模型的数学简化口径，非真实设定；本文结尾"主角在成年第二天被检测触发"由此自洽：成年即入选拔池，次日即检出）。
- **标准**（二选一）：
  1. **躯体强度** ≥ 1.25倍常人。
  2. **神经元活动**超过特定阈值。
- **误判补偿**：因强烈情绪波动达标者，蜂后不修正，而是授予**定制天赋/被动技能**（仅在模拟世界和普通试炼有效），视作一种实验性平衡。
- **流程**：达标 → **入门测试** → 失败（记忆清除）/成功（成为**预备工蜂**）。

### 4.2 普通试炼

- **频率与时间**：每周一04:00强制开启。
  - 试炼内最长7天，现实时间**暂停**。
  - 若超时，则现实流逝1周，试炼内最长21天。
  - 非参与者意识暂停。
- **形式**：意识投入多个独立模拟世界，各有任务线与NPC。
- **核心规则**：
  - **底层代码**：任何试炼**必定存在通关方法**。此规则由L国初始研究员设定，蜂后与AI无法违逆。
  - **“必死试炼”**：蜂后为提升效率，**利用底层代码漏洞设计的、通关概率无限趋近于零的超高难度试炼**，旨在筛选奇迹创造者，并将大量预备工蜂“淘汰”至下一阶段。
- **奖惩**：
  - **失败**：**死亡**。意识数据清除，大脑物理层面可能被回收，模拟世界显示为脑死亡。
  - **成功**：
    - **躯体强化**（上限：改造人基础3倍）。
    - **大脑催化强化**（潜力未知，提升精神力等）。
    - 道具/技能（仅限模拟世界和普通试炼）。
    - **蜂巢币**（虚拟货币，可系统购买或玩家交易虚拟物品）。

### 4.3 晋升与“地狱”真相

- **晋升正式工蜂**：普通试炼等级达标（通常对应属性接近上限）后，可开启蜂巢试炼。
- **“地狱”的本质**：
  - **空间**：**就是虫洞对面的真实星球**。
  - **认知欺骗**：蜂巢向所有进入者灌输——“你已死亡，堕入地狱，唯有通过无尽的蜂巢试炼方能赎罪”。
  - **进入条件**：正式工蜂在**模拟世界或普通试炼中“死亡”**。
  - **生活**：意识永久脱离模拟世界，无法返回，所有活动均在真实世界进行。
- **蜂巢试炼**：
  - **目的**：在真实星球探索、战斗、**采集资源**。
  - **形式**：
    - 进入“地狱”前：**单人任务**。
    - 进入“地狱”后：强制**小队制**（队长、副队长、队员）。
  - **队长特权**：
    - 知晓“地狱即真实”的**部分真相**。
    - 可短暂意识回归蜂巢，**接触并诱导**有潜力的预备工蜂，使其“死亡”后加入己队。
  - **躯体规则**：
    - 蜂巢为参与者制造真实克隆躯体，其属性与模拟角色当前属性**完全一致**。
    - **（关键点）** 若属性未达标准3倍，蜂巢需消耗额外资源培育**弱化躯体**。
  - **奖惩**：
    - **失败**：在真实星球**真实死亡**（意识随大脑毁灭而消亡）。
    - **成功**：根据采集的**物资量**和**装备损耗**结算**能量点**。
      - **能量点**：在“地狱”和蜂巢内部市场流通，用于购买**实体装备**。
      - **装备系统**：分**热量武器**（激光等）、**动量武器**（枪支等）、**其他武器**（声波等）三大类。与蜂巢币购买的虚拟装备**完全隔离**。

## 5.  符文系统：新宇宙的力量接口

### 5.1 基础构成

- **符文**：
  - **形态**：正六边形。
  - **材质**：**符文石**（该宇宙常见矿物）。
  - **结构**：
    - **正面**：特定纹路，决定力量来源与效率。
    - **反面**：**能量通路**。
- **符文板**：激活装置，将基础能量转化为可控能量流。

### 5.2 符文等级与规则

- **基础符文**：产生**三条**同属性能量流。
- **初等符文**：1进1出。
- **中等符文**：2进2出。
- **高等符文**：**3进3出**，且流入能量必须**同源**。
- **特殊规则：末端强化**：当初/中等符文位于能量末端（输入>输出），效果按差值比例获得小强化。
- **效果幅度**（约数）：
  - 一级：+10%
  - 二级：+40%
  - 三级：+100%

### 5.3 蜂巢的符文之路

- **技能系统起源**：为让工蜂适应真实力量，蜂后模拟符文，在系统中创建了技能体系。
- **繁育符文的破译**：蜂后通过研究壁画，**独立发现并掌握了“繁育”力量**。初期效果不佳，后通过研究能量晶体等优化至接近其他体系。
- **三符共鸣**：
  - **触发条件**：**精神**（思维）、**繁育**（生命）、**力量**（物质）的**三级符文**，按正六边形**“均”位**（彼此间隔120°）镶嵌。
  - **现象**：召唤一个与使用者完全一致但性别相反的**性转镜像体**。
  - **原理**：“创造三元”平衡触发生命本质的重构。
  - **蜂后的共鸣**：蜂后在成功研发三级繁育符文后，亦触发此效果，拥有一个**男性分裂体**。
- **使用限制**：符文装卸与效果检测必须在**蜂巢外（真实世界）或“地狱”** 进行。其对个体的强化会同步映射到模拟角色。

## 6.  核心冲突与势力

- **蜂后阵营**：
  - **目标**：执行火种计划，延续文明。
  - **手段**：认知欺骗、效率至上、必要时冷酷无情。
- **反抗军**：
  - **起源**：部分成员发现“地狱”真相，追求自由与知情权。
  - **行动**：渗透、揭露、试图推翻蜂后的管理方式。
- **外部威胁**：
  - **黑暗森林文明**：消灭类猿文明的元凶，科技与符文水平极高，是悬在蜂巢头顶的达摩克利斯之剑。

## 7.  资源体系

- **能量晶体**：生物能量结晶，**蜂巢核心能源**，采集与结算权重最高（~70%）。
- **符文石**：**战略与研究资源**，用于制造/研究符文，结算权重次之（~20%）。
- **其他资源**：特定矿物、生物样本等，用于各类制造，结算权重约10%。
