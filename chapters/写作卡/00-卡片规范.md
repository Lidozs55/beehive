# v2 写作卡规范

> 写作卡是临写前生成的本章约束，不是旧稿摘要、剧情台本或正文替代品。旧轮次卡片不自动继承到 v2。

## 一张卡只回答四件事

1. 谁在本章想完成什么。
2. 什么阻碍迫使人物作出选择。
3. 选择造成什么不可逆或暂时变化。
4. 写作者必须避免哪些事实、视角和知情越界。

## 固定格式

```markdown
# PXXX · 标题

## 本章定位
- 接续：上一章结束时的必要状态；P001 写“无”。
- 目标：谁想做什么，结束时改变什么。
- 视点：人物、距离、时间和地点。

## 必须成立
- 事件与选择：只列改变目标、处境、关系、认知或读者期待的节点。
- 结果：本章结束时已经发生的变化。
- 必要事实：数字、物件、能力来源、制度条件和证据来源。

## 边界
- 人物知道什么。
- 人物不知道什么。
- 读者可以知道什么。
- 不得提前兑现什么。

## 留给正文
- 场景连接、动作顺序、普通对白、情绪过渡和非关键细节由写作者决定。

## 必要原文
- 只有不可改动的制度文本、物件文字、已确认口径或作者指定原话。
- 没有则写“无”。普通对白不得放这里。

## 来源
- 只列本章确实需要读取的文件。
```

## 卡片边界

- 大纲提供方向，卡片提供本章约束，正文负责表达，状态文件记录正文结果。
- 卡片不复制 bible、人物档案或 summaries；只写本章需要的差异和来源。
- 卡片不规定逐句、逐动作、逐段顺序，不保留旧稿的句法和叙述节奏。
- “红线”只有在对应事实风险会阻断正文时才写；不把风格提醒、审计清单和重复禁令塞进每张卡。
- `必要原文`是例外栏，不是对白仓库。凡是普通对白、心理解释和场面调度，都由正文重新生成。
- 一张卡写不下最小约束，说明上游大纲或设定尚未解决，不应继续堆细节。

## 生成和回收

- v2 卡只能由当前大纲、已确认设定和作者裁决生成。
- 旧正文、旧卡和旧摘要只能作为待核参考；引用其中内容时必须重新对照权威来源。
- 写作完成后不按卡片补写正文，也不把卡片计划直接登记为事实。
- 主代理以正文为准更新 `state/`，发现计划未兑现时修改状态，不强行修改正文去匹配卡片。
