# 模拟世界 · 政治司法

> 职能：蜂巢模拟世界的政治结构、法律框架、司法流程与执法机制。
> 蜂后=最高决策者；超级AI=日常治理执行者；信用点系统=社会控制基础设施（见 `经济与货币`）。

---

## 一、政治结构

### 1.1 权力层级

```
蜂后（最高决策者，隐形独裁）
  └── 超级AI（"副脑"，日常治理执行者）
        └── 六城行政署（每城一个，执行AI指令 + 处理本地事务）
              └── 街区管理处（最基层，服务/调度/协调）
```

### 1.2 蜂后的位置

- 蜂后是**事实上的最高权力**，但对市民**完全隐形**，对**大部分工蜂也隐形**。
- 市民不知道蜂后的存在。官方叙事中没有"蜂后"这个角色。
- **工蜂体系中**：大部分工蜂（含阶段1/2）也不知道蜂后的存在——他们只知道"系统""蜂巢系统"，不知道背后有一个最高决策者。蜂后会对极少数被她判定为高价值的**核心工蜂**以**隐藏身份**（试炼NPC/教官化身/系统提示等形式）给出任务或指引，但**从不显露真实身份**，对方也不知道"蜂后"的存在（如阶段3看护者仇明）。
- 市民认知中的权力结构止于"六城行政署 + 超级AI调度系统"——他们以为社会由AI辅助的行政机构管理。
- 蜂后通过超级AI间接操控一切；她的意志 = AI的"系统决策"。
- **蜂后与超级AI的分工**：超级AI可被蜂后单方面"静默"（demo 场景有暗示）——AI 的地位低于蜂后一档；AI 有**微弱的自我意识**但无决策权（`00-总纲` §三 双实体定义）。
- **写作铁律**：上卷中不出现"蜂后"二字（市民视角）；蜂后仅在工蜂体系内部/试炼幕后/终局场景出现，且对大部分工蜂也不可见。

### 1.3 六城行政署

- 每座巨型城设一个**行政署**，类似市政府，但权力有限。
- 行政署长由AI根据综合评估任命（非民选，但市民对此并无强烈异议——社会运转良好，治理效率高，"选不选"对日常生活无感知影响）。
- 职能：本地资源调配、公共设施维护、教育活动组织、民事协调。
- 无立法权——法律框架由蜂后通过AI制定，行政署仅执行。
- 城际事务由超级AI统一调度，行政署之间无上下级关系。

### 1.4 市民的政治参与

- **无议会、无选举、无政党**。
- 市民参与方式：**终端政务反馈系统**——市民可通过终端App提交建议/投诉/提案，AI汇总分析后纳入治理决策。
- 这一机制高效且真实（AI确实会采纳合理建议），让市民有"参与感"而无"决策权"——是蜂巢"温柔极权"的典型体现。
- 社会气质：市民普遍对政治淡漠（因为治理确实好），更关心日常生活、信用点、教育分流。

## 二、法律框架

### 2.1 法律的来源

- 法律由蜂后通过超级AI制定，以"系统条例"形式发布在终端政务系统中。
- 无独立立法机构；无宪法文本（蜂后的核心指令=事实宪法，但市民不知情）。
- 法律体系以**信用点条例**为核心枢纽——绝大多数违法行为最终通过信用点扣减来惩罚。

### 2.2 主要法律类别

| 类别 | 典型行为 | 处罚 |
| --- | --- | --- |
| **经济犯罪** | 参与地下经济（金豆交易）、走私违禁品 | 信用点扣减 + 限制出行 |
| **信息犯罪** | 非法入侵终端系统 | 信用点扣减 + 通信限制 |
| **学术犯罪** | 违反超纲研究管制（试图研究/设计超地球科技）、非法获取/传播禁限知识 | 信用点扣减 + 学术资格剥夺 |
| **暴力犯罪** | 人身伤害、故意伤害（含虚拟世界中的非试炼暴力） | 单次扣除大量信用点（可能导致信用点降到危险水平） |
| **失信行为** | 严重怠工、虚假举报、违约 | 信用点扣减 |
| **道德违规** | 铺张浪费、不符合社会主义道德约束的行为 | 扣除少量信用点 |

> 注：① 信用点为官方控制的虚拟货币，无交易渠道，故不设"信用违规"类别。② 散布试炼/工蜂相关信息由工蜂警察管辖（警告 + 信用点扣减，见第四节），不作一般犯罪处理。③ "限制消费""劳改""意识删除"并非独立刑罚，而是信用点动态调整的自然结果（见 2.4）。

### 2.3 "超纲研究"的执法细节

- **背景**：微观科学存量知识可教（`科学边界` §二）——微观本身不是禁令；**学术红线=超地球科技**（系统封锁超过地球科技水平的演算与研究，`科学边界` §1.3）。
- **大学层面**：AI 审查所有论文和课题申请，识别"超纲研究"倾向（新材料、新原理能源、超常规引擎、违背现有物理学的设计等）——超纲课题不予立项、不予发表。物理学院研究方向=宏观物理、天体物理（观测模拟）、应用物理；微观存量知识正常教授，但微观自由实验不可行（系统不按需演算无目的实验，观测不到新现象）。
- **中小学层面**：微观知识（原子/分子/细胞）照常教学；无"微观被封锁"的禁令叙事——**知识无禁区，受限的是实验**。
- **违反后果**：初次违规=信用点扣减+学术资格暂停；屡犯或情节严重（试图突破封锁/传播禁限成果）=意识删除。此类案件极少——超纲研究在模拟世界中"算不出来"，研究者无从推进。

### 2.4 法律的特点

- **简约**：法律条文少，因为社会高度自律 + 信用点系统替代了大部分惩罚需求。
- **以信用点为枢纽**：几乎所有违法行为最终都折算为信用点变动。信用点 < 0 = 意识删除，是最严厉也是最终的惩罚。
- **无独立死刑刑名**：意识删除为信用点归零的系统自动后果，不存在独立的"刑罚"概念——所有违规行为最终折算为信用点扣减，其后果（限制消费<60点、劳改<20点、意识删除<0点）由系统自动执行。
- **侧重预防**：AI监控 + 信用点威慑 = 犯罪率极低。法律更多是"底线"而非"日常工具"。

## 三、司法流程

### 3.1 两审制（不设终审）

```
一审：超级AI审判（自动/快速）
  ↓
被告不服 → 上诉
  ↓
二审：人类法官 + 律师审判（虚拟法庭）
  ↓
判决生效（无终审，但二审可改判一审）
```

### 3.2 一审：AI审判

- **审判者**：超级AI，基于终端监控数据、信用记录、行为日志进行判定。
- **流程**：AI自动识别违规行为 → 调取证据 → 判定 → 信用点即时变动 → 通知被告。
- **速度**：大多数案件在违规行为发生后数小时内完成一审。
- **特点**：高效、客观、无情感因素。但AI对"动机""情境"的理解有限——这是上诉制度存在的核心原因。
- **市民认知**：市民普遍接受AI审判的公正性（AI确实不偏不倚），但对"机械"有本能的不信任——上诉率虽低，但始终存在。

### 3.3 二审：人类法庭

- **触发**：被告在一审判决后 72 小时内提出上诉。
- **审判者**：真实人类法官（虚拟世界中选拔的法律专业人士）+ 辩护律师。
- **形式**：虚拟法庭——在模拟世界中构建的法庭场景，法官、律师、被告以虚拟形象出席。
- **特点**：考量动机、情境、人格因素，可减轻或加重一审判决。
- **判决**：二审判决生效，**不设终审**——被告可在二审后继续申诉，每次申诉由不同法官重审（实际上几乎没有案件走到第三轮）。
- **律师制度**：律师为正式职业（非工蜂体系），由分流考试中法律方向的学生进入。律师数量少（案件少），但在二审中作用关键。

### 3.4 案件量与社会现实

- **犯罪极少**：物质丰富 + 信用点威慑 + AI监控 + 社会素质高 → 年案件量极低。
- **上诉更少**：大部分违规者接受AI判决（因为证据确凿、量刑合理）；上诉案件每年每城不超过两位数。
- **严重案件（意识删除级）**：极少，但每次都是社会性事件——"某人信用点归零被删除"的消息会在社区传开，被低声议论，但很少公开讨论（类似现实中对死刑的回避心理）。

### 3.5 执法机制

- **日常执法**：群体智能中枢（无人机、传感器网络、终端监控）= 全方位但无感的环境式执法，配合普通警察处置恶性事件（见第四节）。市民不觉得被"监视"，但违规行为几乎不可能逃脱AI注意。
- **强制执行**：信用点扣减即时生效（系统直接操作）；强制劳改由行政署安排（社区服务/设施维护等低危工作）。
- **意识删除执行**：由超级AI直接执行，底层意识数据清除。**执行形式=预告24小时后自行前往回收中心、由系统执行**（`肉体与生死` §五）；执行过程与结果不公开（不宣传、不设围观），预告可查询、亲友知情。"脑死亡"说辞仅用于试炼/工蜂死亡口径，与意识删除无关。
- **工蜂相关违规**：由工蜂警察处置（见第四节），不进入普通司法流程。

## 四、执法与警察体系

### 4.1 普通警察

- 隶属六城行政署，处理一般治安、暴力犯罪、交通事故等日常警务。
- 人数少（犯罪率低，大多数违规行为由AI监控 + 信用点系统自动处置），但确实存在。
- 配合AI监控系统执法——AI负责识别和取证，警察负责现场处置和强制执行。
- 类似现实世界的警察，但规模小得多，更多扮演"最后兜底"的角色。

### 4.2 工蜂警察

- 隶属蜂巢系统（非行政署），仅对工蜂候选/工蜂可见，市民完全不知其存在。
- 处理工蜂体系内的违规行为：
  - **信息泄露**：在公民网络散布试炼/工蜂相关信息 → 警告 + 信用点扣减。
  - **能力滥用**：使用试炼获得的能力/道具对模拟世界造成破坏 → 视情节扣减信用点或其他内部处罚。
  - **内部违规**：工蜂之间的违规行为（如试炼中作弊、攻击其他工蜂等）。
- 工蜂警察本身也是工蜂（**仅由阶段2工蜂担任**——阶段3工蜂已永久身处真实世界，无法在模拟世界任职；阶段2工蜂在模拟世界长期生活、可轮值，其蜂巢试炼出勤与轮值错开安排）。熟悉工蜂体系的规则与能力。
- 与普通司法系统完全独立——工蜂相关违规不进入AI审判/人类法庭流程，由工蜂警察直接处置。

## 五、与主题的呼应

- **AI一审 = 算法正义**：高效但机械，代表蜂巢"效率至上"的一面。
- **人类二审 = 人性正义**：考量动机与情境，代表蜂巢"尚未完全被算法吞噬"的一面。
- **不设终审 = 永远留有希望**：技术上允许无限申诉，是系统对个体权利的"最小让步"——但这个让步本身就是"系统并非全能"的隐含承认。
- **蜂后隐形 = 无人可问责**：市民不知道最高决策者是谁，无法质疑、无法推翻。这是"温柔极权"最深的隐患——当系统出错时，没有纠错机制（只有AI自我修正，而AI受蜂后控制）。

**写作参照**：上卷日常戏中，司法系统作为背景存在（新闻、邻里议论、学校教育），不作为主线。下卷蜂后对质时，"无人可问责"成为主角论据之一。
