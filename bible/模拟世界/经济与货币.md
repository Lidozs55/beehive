# 模拟世界 · 经济与货币

> 职能：信用点制度、政府垄断、三层货币体系与蜂巢币调控。公民日常经济运行规则。
> 信用点"基础流"（每周流入模型）见 `社会结构与经济` §1.3；金豆地下经济的社会纹理见 `社会结构与经济` §二。

## 一、信用点制度

| 项目 | 规则 |
| --- | --- |
| 绑定 | 与个体终身绑定，出生 100 点 |
| 购买力 | 1 点 ≈ 1000 元人民币（旧币）；中档必需品免费 |
| 获取 | 完成社会角色（基础流，见 `社会结构与经济` §1.3）、重大社会贡献、体现信用的行为、举报失信 |
| 消耗 | 非必需品、失信行为、违法犯罪、严重怠工 |
| < 0 点 | **意识删除**（大脑容量上限一亿，为新生/高价值者腾空间；执行=预告+指定处决，见 `肉体与生死` §五） |
| < 20 点 | 强制劳改 |
| < 60 点 | **限制消费**（仅必需品，防透支与赖账） |
| > 1000 点 | 社会特权（公共资源优先权）——**达成渠道=特别评议授点**（科技突破、重大公共贡献等，超级AI提请、极罕见；日常流通无法积累至此，该档为荣誉性设计） |
| 判定 | 超级AI一审（日常自动）；上诉由人类法官二审（两审制见 `政治司法` §三）；不可交易、全程受监控 |

**叙事价值**：信用点是"看得见的系统暴力"。写日常时让它无处不在（购物、升学、邻里举报），但不用旁白解释，让它在事件中自然露出。

## 二、地下经济

- **黄金（金豆）**：实体黄金为地下硬通货，金店为灰色枢纽（金豆来源与双面性详见 `社会结构与经济` §二）。
- **作用**：绕开信用点监控的私密交易——情报、违禁品、虚拟资产转移。
- **叙事价值**：反抗军、灰色情报网的天然接驳口；"系统之外仍有缝隙"的第一处暗示。

## 三、政府垄断与基础设施

- 大部分关键基础设施与关键 App 均由政府垄断运营，整体**适配性/耦合度极高**：设施/App 之间功能低重叠、可互相调用。
- 覆盖：群体智能调度中枢、交通、能源、物流、通信、终端网络。

## 四、经济与工蜂体系的关系

### 4.1 三层货币体系

| 货币 | 使用范围 | 获取方式 | 本质 |
| --- | --- | --- | --- |
| **信用点** | 公民日常生活（模拟世界） | 社会贡献/信用行为 | 社会信用（见 §一） |
| **蜂巢币** | 工蜂体系内部（虚拟道具/技能/论坛交易） | 试炼奖励/任务掉落 | 虚拟世界内价值 |
| **能量点** | 真实世界（地狱）装备/符文 | 真实采集（能量晶体/符文石） | 对蜂巢的实际产出价值 |

> **术语定名**：**能量晶体=实物；能量点=记账单位（简称"点"）**。

### 4.2 单向兑换原则

- **单向兑换（有限）**：能量点可按系统设定的汇率**单向兑换为蜂巢币**，但反向不可；能量点**不能兑换信用点**（信用点=社会评估指标，无交易渠道）。
- **价值层级**：能量点 > 信用点 > 蜂巢币。

### 4.3 蜂巢币的价格调控

- 道具/技能的价格以其强度（0–6级，见 `力量体系` §5.2）为基准——强度越高，价格指数级上升（呼应 E=A·(eˣ-1) 公式）。
- 蜂巢系统作为"发行方"宏观调控（控制试炼奖励产出量、商店定价、稀有道具掉率）。
- 市场波动：论坛存在玩家驱动的情报/道具交易市场（见 `面板与论坛`），价格受供需影响。
- **蜂后允许一切交易**：蜂后不干涉蜂巢论坛上的任何交易形式。

### 4.4 阶段2投资逻辑

- 蜂巢投入培养资源（躯体/道具/配额），换取真实星球采集资源（结算为能量点→可兑蜂巢币/等级经验，`经济与货币` §四）——宏观"投资回收"关系。
- **叙事价值**：货币层级反映了工蜂在蜂巢中的"价值"——虚拟世界的成就（蜂巢币）对蜂后不值一提，真实世界的产出（能量点）才是她真正在乎的。
