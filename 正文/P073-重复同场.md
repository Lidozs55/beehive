# 第七十三章 重复同场

黑是从当中断过去的。没有响动，没有字，也没有那封一直挂着的邀请函。前一分钟陆沉还坐在自家床沿上数呼吸，一下是一下，指尖搭在膝盖上。手机在枕头边扣着，他看了一眼，四点差两分。

四点这个数他认得。四条医嘱外头还挂着半条，别在半夜核对时间。他核了。核完，黑就落下来了。

没有失重，没有下坠，耳朵也没嗡。就是黑，像有人把这一页从册子里整页抽走了，前后两页对不上茬。他试着回想断的那一下，跟前三回一样，接不上。断的地方没有缝。

再亮起来，头顶是一盏小灯，黄的，罩着铁丝网。

灯底下全是绿的。漆皮座面，墙裙，行李架，一色的绿，掉皮的地方露着底下的黑铁。车轮磕着轨缝，一下，一下，隔一节枕木磕一声。窗外没有灯，夜是整块的，玻璃上浮着他自己的影子。空气里有烟油味，汗味，还有谁行李里隔夜的饼味。

他先照老规矩把自己过一遍。衣服还是家里那件，兜掏空了——本子没跟过来，笔也没跟过来。左手腕上多出一条白胶皮带子，接口压死，指甲抠了两下，纹丝不动。带子内侧贴着一粒小灯，绿的，亮着，不闪。

抬手，页就来了。灰底白字，头一行名字，第二行零四四九，都没动。主目标那一栏换了：

主目标：结束本次运输，抵达有效终点。

底下没有细则，没有站名，也没有日子。他往下翻了一页，又翻回来，页上没有别的新东西。陆沉把"有效"两个字多看了一遍。运输是运输，终点是终点，中间添上"有效"，就是备着有不有效的。这一眼他记在心里，没往下想。

生地方先数门。车厢两头各一道门，一扇锁着，一扇虚掩。窗六扇，窗扣全焊死了，玻璃沿一圈漆封。他数完，把数搁下。

车厢比从外头看着长。他这节人不多。斜对面四十多岁的女人，蓝布包袱抱在怀里，脚边网兜里一只搪瓷缸，随着车身磕出细碎的响。靠窗的中年男人穿件旧夹克，领口磨得发亮，闭着眼，手却一直搭在膝上的包袱上。车尾坐着个瘦高老者，背挺得直，脚边立一根拄棍。再往后，灰呢外套的中年人怀里横着个木匣，手搭在匣盖上，谁从跟前过，他都往回拢一拢。

前四回，一回是房子，一回是城，一回在镜子里，一回没有声音。这是第五回。回回都是这样，没有邀请，没有按钮，没有给人犹豫的工夫。

斜前方靠窗，坐着沈知薇。

她也在看腕带。察觉到这边，抬眼，两人对上了视线。谁也没起身，谁也没出声。协议里定过的：再同场，先各自就位，对上账再说话。过了一会儿她起身换座，隔着过道坐到他斜前方，中间隔一个生人。坐下以后她的视线扫过车厢一圈，从车尾扫到车头，一个一个过脸，落回自己膝上。陆沉懂了。她看人，他看车。

车厢里还有四个佩一样腕带的。

靠过道的男人三十一二岁，票捏在指间，对折了又展开，展开又对折。连接处那头，宽肩膀的小伙子正推门，一扇推不开，换一扇，推出一条缝，风灌进来，铁腥味，他眯着眼往缝里看。靠窗的短发姑娘膝上摊着小本，笔在纸上走，一条横线，线上等距点了六个点。还有一个男人歪在座上打盹，帆布包搂在怀里，搂得实。

捏票的男人先站了起来。

"各位，对一下票。"他冲这节车厢拱了拱手，"我姓乔，乔慎，干客服的，接热线，替人对规则对惯了。这腕带咱六个有，别人没有。页上的主目标，劳驾各位挨个念一遍，对齐了再说话。"

六个人各念各的。结束本次运输，抵达有效终点。一个字不差。乔慎说对上了，票也过一遍。

票是硬纸的，比指头长不了多少。到站栏印两个字：家园。日期栏空着。乔慎又对了对光，起点栏也空着。

"咋没有日子？"蓝布包袱的大婶把票翻过来又翻回去，"我买的哪趟车，总得有个日子。"

"我也在找这个日子。"乔慎说，"起点也没填。上车的地方，票上不作数。"他把票翻到背面，那面印着细字，挤得密，灯底下认得出个头几行。他眯眼念了半行，摇头，说字小，回头借灯慢慢看。

短发姑娘把小本转过来。一条横线，六个点，点上标着号。

"顾环，学机电的，刚毕业。"她说，"行车图。站名猜不出来，先占位，车到哪儿，我填哪儿。"

"图是猜的。"乔慎说。

"图先画上。"顾环说，"车不说话，图说话。"

连接处那扇门被推到底，宽肩膀退了回来，拍了拍手上的灰。

"石铮，搬设备的。"他说，"一扇锁死，一扇能开，通下节车厢。下节也是乘客，都在睡。我数了，那边空座多，过道窄，真有事，人从这头过不去那头。"他从怀里摸出个手帕包的小方块，捏了捏，又塞回去。

打盹的男人这时候醒了，先捋袖口，捋完把帆布包搁上腿，拉开，一样一样往外掏：票，笔，小本，一截绳子。掏完数一遍，四样。又数一遍，还是四样。

"程业，做采购审计的。"他说，"出门在外，家当当面点清。"

"两位呢？"乔慎看向过道这边，"一块儿的？"

"认识。"沈知薇说。

"沈知薇。"她报了名，没往下添。

"陆沉。"

乔慎等着，等了两拍，没等来下文，也就不问了。他掏出小本，把六个名字一笔一笔记上，从头念一遍，没一个人提出改。

陆沉下意识去摸兜，摸了个空。账只好记在心里。同批六人。他与沈知薇，第二回同场。前四场，同批的人没重过样，一回都没有。编配要是随机的，同一拨人再碰上，摊到个人头上，摊不出百分之一。数算完了，结论没有。页上不答的话，问了也白问。

沈知薇借转身的时候压着声说："先记着。跟同日生日一样，记进待查，别往一块儿凑。"

"记着呢。"陆沉说。

"还有一条。"她说，"咱们俩这层先别铺开。他们六个人头一回报数，报得越素越好。"

"嗯。她看人，我看车。"他把后半句咽了回去，只说，"分工照旧。"

大婶凑过来，冲着乔慎，也冲着这边："你们六个，是一个单位的？"

"今天是了。"乔慎说。

大婶点点头，像懂了，说一个单位好，路上有个照应，又把包袱拢了拢。

乔慎应了一声，把大婶那张票也借来看了一眼，还回去时照原样折好。

顾环在本子角上记了一笔：腕带六个，乘客没有。写完她抬头发问："几点了？谁有表？"

没有人有表。她把"无表"两个字写在图角上，又在底下画了道横线，等着填。

陆沉也扫了一圈车厢。没有钟，墙上没有，柱子上也没有。这半年他夜里不核时间，这会儿想核也没得核。

石铮把能开的那扇门又推了推，确认它开着："到站就下，完事？"

"票上就一个到站。"乔慎说，"到了再说。丑话搁前头，谁也别先乱动。"

程业把掏出来的四样东西又点了一遍，收包，拉链拉到头，包带在手里绕了两圈。

车厢那头的门响了。乘务员过来，深色制服，票夹夹在胳肢窝底下，手里一把剪钳，还拎着盏手电。夜里的车厢灯暗，他就着手电收票，挨座剪口，还票，话不多。咔，咔。

"同志，"大婶拦住问，"这车到不到绿汀？"

"到站听广播。"乘务员说。咔。

旧夹克男人没睁眼，票从夹克兜里摸出来递过去。剪了，还了。手电的光在他脸上一扫，过去了。

车尾的瘦高老者双手递票，两根指头捏着票边。乘务员接了，剪了，还了。老者点了下头，没话。

到灰呢外套那儿，手电的光先落在木匣上。乘务员的剪钳顿了顿，没问，剪了票走人。匣盖上的手一直没挪。

到程业跟前，乘务员停住了。剪钳举着，人看票，看帆布包，又看人。这一站，站了别人三倍的工夫。程业捋了下袖口，把票递过去。咔。乘务员收了手电，走了，走到车厢那头，又回头看了一眼。

程业把票夹进小本，抬头正对上陆沉的视线。

"看我干啥。"

"没看你。"陆沉说。

大婶把剪过口的票凑到灯底下看。剪口正落在"家园"两个字当中，把园字豁成两半。她用拇指抹了一下，没抹平，把票塞回包袱夹层，手在夹层外头按了按。

喇叭先滋了一声，电流的毛刺听得见。

"旅客们，前方到站，家园，停车三分钟。"

就这一句，喇叭又静了。

旧夹克男人睁开了眼，坐直，把包袱往怀里拢了拢，不看书，不看窗，就看前头椅背。大婶扒着玻璃往外看，外头还是黑的。顾环把横线上第一个点描实，旁边注上"家园"两个字，笔尖顿了顿，又在点外画了个圈。乔慎把自己那张票又展开，看了一眼到站栏，折回原样。石铮从连接处回来，站在过道里，没坐。程业把包带在手里又绕了一圈。

车轮声变了。轨缝一声跟一声，距离拉长，车身往前栽着减。铁底下有什么换了劲，哐当声里带出一段空响。

"停车三分钟。"乔慎把这五个字念了一遍，"到站下车，三分钟，够干什么的？"

没人接。

大婶坐回去了，网兜往脚边收了收。旧夹克男人从兜里摸出票看了一眼，又揣回去，还是看前头椅背。

陆沉数着轨缝。一声，一声，往没了声的那头数。窗外还是黑的，头一盏站灯还没亮。
