## 二、主线脉络

```
8岁入巢（迁移记忆缺失，主角是极少数察觉"被拿掉的时间"者）
→ 18岁生日（3月末）后 04:00 无通知拉入入门试炼"生日快乐"（6人，通关2人：主角+女一沈知薇；淘汰=老师+3路人）
→ 预备工蜂（阶段1）：面板/论坛 → 预备试炼"蜜城"（第7–10章，5月，体制恐怖：交出名字换捷径的温柔吞噬）→ 分流考试（第13章，6月上旬，对标高考）→ 大学录取落定（陆沉=人工智能，沈知薇=生物医学，贺骁=体育系，姜黎=信息管理）
→ 暑假（7–8月）：正式试炼1"镜城"（第14–17章，男二贺骁初登场+自我对峙+NPC异常首现）→ 日常（贺骁/姜黎线下初识、论坛冲突）→ 正式试炼2"无声之城"（第19–22章，女二姜黎初登场+精神系高光）→ 日常（义气冲突/灰色麻烦）→ 正式试炼3"零点列车"（第24–27章，主角×女一唯一重复同场+沈知薇弧光+规则解密）
→ 正式试炼4"三号场"毕业考（8月末）：越级击杀仇明，晋升通道开启
→ 大学开学（9月）与日常：0号实验室档案（AI侧）+ 女一证据线（生物侧——载体待定，候选：流行病学统计异常）双线并进
→ 卷末：约定一起查；"高级试炼"邀请在路上
→ 【中卷=阶段2】：等级达标 → 蜂巢试炼（地狱单人任务，以为高级试炼）→ 符文研发/倒卖/蜂后博弈 → 对"秘境"的怀疑加深
→ 【下卷=阶段3】：必死试炼"死亡" → 地狱真相 → 小队制 → 反抗军 → 与蜂后对质 → 地球侧单向档案（蜂后证物） → 开放结局
```

> 时间锚点：分流考试=6月上旬（第13章，对标高考）；脉络中"大学"指**录取落定**（非开学）；三号场=暑期末（8月末，第28–31章）；大学开学与日常=9月起（第32–38章）——与 `bible/模拟世界/科学边界` §4.3 锚点一致。
