## 一、就业与劳动结构

### 1.1 全民有岗（无失业概念）

- **不存在"失业"**——每个成年人都有一个"社会角色"（工作/学习/照护/研究），由系统按能力评估自动匹配。
- 社会角色的分配=系统的"稳定设计"：人人有事做 → 社会稳定 → 欺骗稳定。
- 匹配逻辑：以分流考试（`城市与教育` 教育体系）为第一分配节点；后续按表现动态调整。
- **人口基数（1 亿）**：六城合计约 1 亿人口，每城约 1600 万+；社会体量正常（论坛活跃度、就业结构、文化生产都有足够基数）。

### 1.2 人类岗位的分布（自动化不擅长领域）

| 领域 | 岗位示例 | 说明 |
| --- | --- | --- |
| 维护（最大就业面） | 无人机维修、调度节点维护、传感器检修、产线保养 | 黑箱手册操作员（`科学边界` §1.4）；"维修岗"= `城市与教育` 的高需求职业 |
| 医疗健康 | 医生/护士/影像技师/康复/公共卫生 | 黑箱医学（`肉体与生死` §二） |
| 教育 | 教师/教务/教育研究 | 快乐教育+过程性评价 |
| 科研 | 课题组研究员/数据分析/实验员 | 宏观层研究+存量知识层（`科学边界` §二） |
| 农业精细环节 | 农技员/畜牧/渔获/质检 | 自动化+人类复核（林越的职业方向） |
| 管理与协调 | 行政署/街区管理处/调度协调 | 执行层（`政治司法` §1.3） |
| 公共服务 | 警察/消防/社区服务/临终关怀 | 人数少、兜底角色 |
| 文化艺术 | 创作者/艺人/体育选手/场馆运营 | **活跃**（1 亿人口+充足休闲时间） |
| 照护（非正式岗位） | 育儿/养老照护=社会角色 | 计入信用流 |

### 1.3 信用点的"基础流"（经济底层逻辑）

**信用点的本质：以货币为外壳的社会评估指标，不是传统货币。**

- 表面：1 点≈1000 元购买力（`经济与货币`）——"消费"=非必需品配额的使用。
- 底层：**信用点=个体社会表现的动态评估**。
- **基础流入**：
  - 完成社会角色（工作/学习/照护）→ **每周基础流入 1 点**；
  - 表现较差（怠工/失职/低效）→ 该周流入**扣至 0 点**；
  - 表现突出（高效/超量/创新贡献）→ 该周流入**增至 2 点**（少数）。
  - **评定方：超级 AI**。
- **为什么必须有基础流**：若信用点只消耗不流入，全社会人人迟早归零——系统必须保证"守规矩的普通人"可持续生活。
- **收支平衡模型**（作者内部参照，不写进正文）：基础流入约1点/周（全年约50点）；日常非必需消费年均约40–60点；违约/失信/犯罪一次性扣5–100点。
- **叙事价值**：信用点从"存款"变成"表现分"——日常的"信用点意识"（AA制/不欠人情）有了底层逻辑；"举报失信"能获得信用点（举报=社会监督的表现）。

### 1.4 劳动的意义（深水）

- 系统需要劳动吗？——大部分生产自动化了。但**系统需要"人人有事做"**：空闲=胡思乱想=危险。
- 上四休三的真相：**劳动量是"分配"出来的**——把剩余的、有意义的人类工作摊给所有人，同时保留大量休闲时间。
- **讽刺**：公民觉得"这是物质丰裕、节奏从容的理想社会"——但设计目标是"稳定"，不是"幸福"。

## 二、黄金与金豆的来源

### 2.1 黄金在模拟世界的"实体性"

- 模拟世界存在金矿/金饰生产？——否。**黄金=系统生成的对象**：金饰店出售的"金饰"是系统预设的奢侈品数据模块（合法消费，扣信用点；制造由按需演算支撑，`科学边界` §一）。
- 公民认知：黄金是贵重品（旧世界共识延续）；金店=正经首饰店（行政署发执照，合法纳税）。
- **金豆的本质**：金饰在私人间流转的昵称。**"金豆交易"=实物（金饰）所有权转移**——不经过信用点系统的监控账本。
- 为什么金饰能成为"硬通货"：① 价值共识（旧世界共识延续）；② 可验证的实物性（系统标准件，防伪特征）；③ **所有权转移不可追溯**。

### 2.2 金店的两副面孔

| 面孔 | 业务 | 系统态度 |
| --- | --- | --- |
| 合法面 | 金饰销售（信用点消费）、以旧换新 | 允许（奢侈品消费，合法） |
| 灰色面 | 金豆兑换/保管/撮合（口头约定、不落账） | **默许但不承认**——打击成本高；金豆网络甚至是"系统监视地下动态"的暗桩 |

### 2.3 金豆经济的社会纹理

- 流通场景：灰色交易（违禁品/情报/虚拟资产转移）、大额私人借贷、无法用信用点表达的"人情"。
- 风险：信任风险（不认账）、被钓鱼（系统钓鱼执法）。
- 姜黎家的定位：金店世家（金豆网络的节点）；姜黎的"姜老板"ID=论坛情报贩子——**金店=实体节点，论坛=信息节点，同一张网**。
- **叙事价值**：金豆网络=反抗军/灰色情报的接驳口；"系统并非全知"的第三处暗示（金豆、旧城、按需演算边界）。

## 三、媒体、舆论与历史叙事

### 3.1 官方新闻（日更·CCTV1 式）

- 机构：官方新闻（行政署下设，终端 App 内置"新闻"模块）。
- **更新频率：每日更新**，类似 CCTV1 的新闻联播——每天固定时段推送《要闻》+ 滚动资讯。
- 内容结构：要闻（建设成就、政策、重大事件）+ 民生（教育/医疗/交通）+ 文体 + 科技（宏观层成果）+ 天气。
- 报道口径：灾难相关只谈"重建"与"纪念"，不谈"灾难本身"；删除相关不报道（执行公开但官方不提）；系统/试炼不报道；国际/外太空不存在（官方叙事"其他地区灾后失联/封锁"）。
- 新闻的"社会节奏"功能：每日新闻给公民共同话题，维持"正常世界"的观感。

### 3.2 民间舆论场

- 终端论坛（`终端网络` §二）=民间舆论场。
- 审查分级：允许都市传说（周一怪谈——低频、无法证实）、娱乐八卦、生活话题；删帖=试炼/工蜂/真相相关（AI自动删+工蜂警察介入，`政治司法` §四）；引导=重大事件后官方"权威解读"帖。
- **"敏感话题会被删"这件事本身是禁忌**——被删帖者不会声张。

### 3.3 历史教育

- 历史课内容结构（中学）：灾难前文明简史（简化+神话化，**刻意不谈战争/核武/衰败**）+ 灾后重建史（官方版）+ 灾难本身=模糊的创伤事件（细节永久空白）。
- 一代公民：亲历者，对官方叙事"半信"（知道细节被隐去，但无从查证）。
- 二代公民：完全接受官方叙事（"六城一家"认同）——**代际差异的认知层**。

### 3.4 政务反馈系统

- 市民提案→AI 采纳。反馈系统=**安全阀**（公民有"参与感"而无决策权）。
- 深水：真正重要的提案（涉及真相边界）会被"合理驳回"（"经评估不可行"）——公民永远不会知道自己的提案触碰了什么。

## 四、信仰与民俗

### 4.1 官方立场

- **无神论 + 科学主义**（教育灌输）；无任何建制宗教。
- **模拟世界内的大部分人都是无神论者/科学主义者**——绝大多数人理性、务实、不信鬼神。

### 4.2 灾后民俗：几乎为 0

- **灾后民俗几乎为 0**：10 年来（虚拟观测）没有形成显著的民间信仰/仪式文化。原因：官方科学主义教育彻底；灾后生活稳定繁荣；系统刻意淡化。
- 旧世界节日（新年/端午/中秋等）作为**世俗节日**保留（放假、聚餐、送礼），但**没有宗教仪式内涵**——是"家庭团聚的节日"，不是"祭祖/祭祀的节日"。

### 4.3 试炼怪谈与正常生活无关

- **试炼内怪谈与试炼外正常生活无关**：试炼世界自行产生试炼所在的世界观设定（每个试炼世界自带完整世界观，与模拟世界互不渗透）。
- "第七个孩子"的禁忌仪式=**试炼世界内部的设定**，**繁育力量不会渗透至虚拟世界内**——模拟世界的公民生活中不存在任何超凡力量的痕迹/传说。
- 周一 04:00 怪谈：存在但**极淡薄**——偶尔出现在论坛深水帖/闲聊里的都市传说（"周一凌晨四点别醒着"），被大部分人当作无聊玩笑；不日常化、全书不必提及太多。

### 4.4 死亡观（衔接 `地理与六城` §3.2 / `肉体与生死` §五）

- 自然死亡：安详临终+简朴告别仪式（`肉体与生死` §三）。
- 意识删除：可查询的程序化处理（`肉体与生死` §五）——社区"知道但低声议论"，执行过程与结果不公开。
- 试炼死亡：对外"突发脑死亡"——公民几乎接触不到。

## 五、养老与代际

### 5.1 退休与养老

- 退休：55–60 岁（沿用旧世界惯例）；退休=终身保障（退休金=基础信用流，不再需要社会角色）。
- 养老形态：居家养老+社区照护为主；老年公寓为辅；成年子女照护父母=社会角色（享受信用流）。
- 一代老龄化时间表：蜂巢运转 10 年（虚拟观测），入巢时 30–50 岁者现年 40–60 岁——**上卷时期正是第一批退休潮的开始**——社会开始出现"养老话题"，但远未到危机程度。（注：真实时间已流逝 20 地球年，但生命周期按虚拟世界观测，见 `01-历史年表` §〇）

### 5.2 代际差异（认知层）

| 维度 | 一代（有灾难前记忆） | 二代（蜂巢出生，尚幼） |
| --- | --- | --- |
| 历史认知 | 记得旧世界；对官方叙事半信 | 完全接受官方叙事 |
| 怀旧 | 强烈（旧电影/旧物/家乡菜） | 无感 |
| 故乡 | "故乡"=旧世界的地点 | 故乡=蜂巢六城 |
| 对系统的态度 | 感恩+隐忧 | 全然接受 |
| 信仰 | 无神论（多数）；极少数残留模糊记忆 | 彻底的无神论者 |

- **主角的位置**：8 岁入巢=一代的幼年入巢者——有旧世界记忆碎片（车窗外的雨、女人的手、玻璃上的圈），主体记忆形成于蜂巢。他同时拥有一代的"旧世界微光"和二代的"蜂巢原住民感"。
- 林越的对照：不追问的陆沉——"不知情也是一种幸福"的活样本（`chapters/04` §3.2 D4）。
