# v2 章节派发协议

> 派发只把一张 v2 写作卡和必要来源交给写作者。卡片不是脚本，回执不是事实台账。

## 派发块

```text
你负责创作 PXXX《标题》。

交付：只写入 正文/PXXX-标题.md，不修改其他文件。

本章目标：谁想做什么，遇到什么阻碍，结束时什么改变。

读取：
1. style-guide.md
2. chapters/写作卡/PXXX.md
3. 卡片“来源”列出的设定和人物文件
4. 上一章 v2 正文；P001 无
5. 主代理提供的当前状态窗口

写作边界：
- 以人物行动、选择和后果完成本章，不写核验报告。
- 卡片只规定必须成立的事实、因果和边界；场景连接、动作顺序和普通对白自行完成。
- 不把旧正文当句式模板，不补写卡片中没有的旧稿细节。
- 遇到设定冲突、证据缺口或知情边界无法成立，停止冲突部分并报告，不自行发明规则。

回执：
- 正文路径和字数
- 本章实际完成的主要变化
- 与卡片的有意偏离
- 需要主代理回收的事实、钩子或冲突
```

## 主代理回收

1. 阅读正文全文，先查事实、因果、视角和知情边界。
2. 以正文实际内容更新 `state/`；卡片和回执不能直接变成事实。
3. 需要改变设定或长期计划时，先登记作者裁决，再同步大纲和属主文件。
4. 通过连续性检查后，才生成下一章卡。

## 禁止事项

- 不给写作者派发全卷摘要、全卷人物状态或后续答案。
- 不把旧轮次卡片称为 v2 卡片继续派发。
- 不用词频、固定段数、固定对白比例或逐项覆盖率代替人工审稿。
