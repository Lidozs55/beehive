## 〇、时间双轨与换算（先读此节）

**周制**（详见 `工蜂体系/周制与筛选`）：

- 每周一 04:00=全局切换点；单周=虚拟世界运行周；双周=试炼世界运行周（虚拟世界冻结、非参与者时停）。

**换算关系（硬规则）**：

| 项    | 虚拟世界观测（蜂巢纪年/公民日历） | 真实时间（地球/遗落之星/地狱）   |
| ---- | ----------------- | ------------------ |
| 年    | 1 年               | 2 年（虚拟 1 年=真实 2 年） |
| 周    | 1 周               | 2 周                |
| 试炼间隔 | 3 / 4 / 5 周       | 6 / 8 / 10 周       |
| 故事开始 | 蜂巢纪年 10 年         | 火种计划后约 20 个地球年     |

- **生命周期/年份周期均在虚拟世界内观测**：公民的年龄、衰老、日历一律按虚拟时间（蜂巢纪年）计算；真实时间（20 地球年）只在地狱/遗落之星一侧可观测。

- 上卷/中卷按虚拟时间叙述（读者跟随公民视角）；**下卷主角进入地狱后，时间叙述转为真实时间观测**（但蜂巢纪年仍作对照标注）。

## 二、蜂巢纪年（新历）——以蜂巢建立为元年（虚拟世界内观测）

| 时间    | 事件                                                                                                                                                                                                                                                     |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 元年    | 一亿大脑在蜂巢营养舱苏醒，进入模拟世界（"随机灾难"叙事启动）；六座巨型城市重建完成；**主角陆沉（8岁）随记忆采集入巢**；**普通试炼体系元年即开启**（周一04:00制·周制——写进蜂巢底层代码，蜂后不可修改，初始即运行）；**工蜂选拔机制同步启动**——选拔扫描覆盖全体成年公民（持续监测，不限18岁，元年已成年者自元年起入池）；**机器人采集开始**：蜂后以机器人+武器采集能量晶体（物质换能量，持续亏损期，见 `真实世界/蜂巢本体` §1.6） |
| 元年–3年 | 社会工程落地：信用点系统、教育分流、地下经济（金豆）成形；机器人采集持续亏损（决策/反应速度低、灵活度差、野外遭遇战劣势、装甲被兽群磨死、科技克星野兽、躯体丢失=物质损失）；**工蜂无符文使用**（符文体系未破译）                                                                                                                                      |
| 2年    | **首批 phase2/3 工蜂出现**（phase1 等级达标者首次参与蜂巢试炼、虚拟死亡者转入 phase3）——人力采集开始，处于上升期（机器+人工混合期；机器人主要于纪年1–3年启用）；**转入即告知"已死亡、进入地狱服役"（认知欺骗自首批转入即运作）**                                                       |
| 3年    | **符文研究起步**：蜂后探测器发现壁画遗迹存在 + 早期采集工蜂带回具体符文样本 → 蜂后独立研究破译（**科研主体=蜂后本人**，极少借助工蜂、很少接触；工蜂较少意识到科研重要性）                                                                                                                                                     |
| 4年    | **符文研发初步成果**：初等符文装备 phase2/3 工蜂（真实世界使用）                                                                                                                                                                                                                |
| 5年    | **人力采集到达稳态、机器人全面弃用**（物质换能量→能量换能量，净积累期）；蜂后意识到可让工蜂更早接触符文力量——**模拟世界技能商店上线**（模拟符文逻辑）                                                                                                                                                                  |
| 6年    | **繁育符文独立破解**（初期效果差）；精神/力量两系借**类猿遗留符文技术**辅助破译（进展较快）；"必死试炼"设计成型                                                                                                                                                       |
| 7年    | 蜂后触发三符共鸣，获得男性分裂体（可随时与本体合并、按需分裂，作"马甲"执行外部任务） |
| 8–9年  | **反抗军萌芽**：部分工蜂发现地狱真相。反抗军主体=phase3（情报以口头交流为主，借前哨自由市场）；对 phase1/2 渗透时在金豆/地下经济渠道有动作（地下情报网发育） |
| 10年   | **故事开始**：陆沉18岁成年（入巢10年）——成年即进入选拔扫描池（持续监测，不限18岁），周一04:00神经元阈值检测触发，送入入门测试"生日快乐"                                                                                                                                                                       |
| 10年秋 | 中卷：大学开学（初秋）+ 地狱初入 + 符文研发（虚拟时间；真实时间=20地球年+）——上卷结束于8月末（三号场毕业考），暑假（7–8月）属上卷 |
| 11年   | 下卷：队长之路 + 反抗军 + 与蜂后对质 + **地球侧实体硬盘/核废墟证物确认**（核废墟确认=蜂后持有的地球侧硬盘证据，非主角亲历回归）（真实时间≈22地球年）                                                                                                                                        |

**对应真实时间参考**：蜂巢元年≈火种计划后约10个地球年（含记忆采集、方舟迁移、落地苏醒的间隔，写作时微调）；故事开始（蜂巢10年）=真实约20个地球年。
