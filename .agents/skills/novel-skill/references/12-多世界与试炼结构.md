# 12-多世界与试炼结构

## 模块定位

本模块服务于采用跨世界、模拟环境、任务式试炼、封闭场域、规则谜题或阶段性世界切换的作品。它既可用于科幻，也可用于悬疑、冒险、奇幻或混合类型。

它不是传统无限流模板，不预设主神、轮回者、死亡淘汰、积分商城、固定队伍或“每卷一个副本”。作品没有采用的机制，不设计、不检查。

相关模块：全书与故事弧归《02-大纲架构》；悬念公平性归《04-情节与悬念》；规则与科技可信度归《08-世界观构建》；跨环境状态归《09-长篇状态管理》。

## 一、先确定结构用途

使用多世界或试炼结构前，先回答：切换环境为作品带来什么单一世界难以提供的价值？

常见用途包括：

- 用不同环境反复检验同一主题，但每次改变变量。
- 让人物在高压条件下暴露选择、关系与认知偏差。
- 逐层揭示上层系统、真实世界或科技机制。
- 提供不同类型体验，同时让主线、人物与因果持续累积。
- 把抽象制度或技术伦理变成可行动、可失败的局部模型。

若每个世界只换皮，不改变人物、主线认知或上层系统，结构会退化成互不相干的短篇合集。反过来，如果作品只需要一次封闭试炼，也不必搭建循环系统。

## 二、三层结构

按作品实际需要选用，不要求三层齐全。

### 上层现实

回答角色为何进入、谁制造或维持系统、系统与现实社会如何交换人力、信息、资源和权力。科幻作品尤其需要关注技术来源、组织利益、基础设施、观测与干预能力。

上层现实不能只在终局突然出现。即使角色无法直接接触，也应通过故障、偏差、物资来源、语言痕迹、管理员行为或因果残留留下可回溯证据。

### 中层机制

任务如何生成，环境如何切换，信息如何保存，失败与退出意味着什么，时间、身体、记忆和资源如何跨越边界。

这些问题不必一次解释清楚，但作者应知道当前答案或明确哪些仍是开放设计。对角色公开的规则、角色推测的规则和真实机制要分开记录。

### 局部世界或试炼

每个局部环境有自己的目标、阻力、社会关系和审美质感。它应当作为一个有生活纹理的世界成立，而不只是机关房。

一个局部弧线至少要改变以下一项：人物关系、主线认知、能力用法、伦理立场、上层机制理解或现实资源。若全部复位，该弧线对长篇没有累积价值。

## 三、最小设计卡

只填写当前弧线真正需要的字段：

| 字段 | 要回答的问题 |
| --- | --- |
| 叙事功能 | 这一段检验谁、推进哪条主线、改变什么理解？ |
| 表层目标 | 角色眼下认为自己要完成什么？ |
| 真实压力 | 真正迫使角色选择的是什么？ |
| 已知规则 | 角色进入时可靠地知道什么？来源是什么？ |
| 待验证假设 | 哪些只是推测、传言或诱导？如何验证？ |
| 隐藏机制 | 作者掌握但暂不公开的因果是什么？ |
| 人际结构 | 本地人物或队伍成员各自想要什么？ |
| 资源与代价 | 什么能带入、带出、消耗、污染或失去？ |
| 主线接口 | 本弧线如何连接上层现实和前后弧线？ |
| 离场变化 | 离开时哪些状态不可复位？ |

不要求每个弧线都有惊天反转。功能可以是关系深化、失败累积、伦理选择、世界观证据或短暂喘息。

## 四、规则发现与公平性

规则驱动情节的核心不是列规则，而是让角色经历“观察 - 假设 - 试探 - 反馈 - 修正 - 利用或承担后果”。可跳步，但不能让正确答案凭直觉降临。

区分四类信息：

- **明示规则**：由可靠系统或可重复现象给出。
- **经验规则**：角色从有限样本归纳，可能不完整。
- **诱导信息**：由利益相关方提供，不自动等于假话。
- **底层机制**：解释前三类为何表现如此的真实因果。

公平性底线：决定成败的关键信息应在结果前以可感知形式出现；角色可以误读，文本不能在揭晓时凭空补发钥匙。

规则可有例外，但例外必须来自更精确的适用条件、不同层级的机制或可见干预，而不是“主角特殊”。揭示例外后，旧规则应被重新表述为边界更准确的新规则。

## 五、科幻机制的可信度

科幻元素不要求写成工程论文，但要守住因果与尺度。

- **能力边界**：技术能做什么、做不到什么、精度和延迟如何。
- **资源账**：能源、算力、带宽、材料、维护、人力或时间至少有一项形成约束。
- **观测边界**：系统能看到什么，是否存在盲区、噪声、权限和解释误差。
- **社会后果**：重要技术会改变制度、经济、身份或伦理，不应只改变战斗方式。
- **故障逻辑**：故障应从结构、环境或人为干预中产生，并保持同类原因的表现一致。

解释深度服从当前场景。只需让读者理解角色为什么这样判断、这次行动赌了什么；更深机制可延后。

## 六、人物与队伍

队伍不是职业槽位集合。分工可以提高行动清晰度，但人物还需要彼此不完全兼容的目标、信息和风险偏好。

- 冲突优先来自利益、认知和价值差异，不靠临时降智。
- 成员的专业能力应在决策中留下独特痕迹，而不只在轮到其解题时出现。
- 死亡、离队、背叛和牺牲不是强制配额；只有它们改变幸存者、队伍策略或上层局势时才有价值。
- 新成员加入后，应改变现有平衡，而不是机械补齐缺位职业。
- 本地人物拥有自己的生活与目标，不应只负责讲规则、送线索或成为牺牲品。

## 七、跨弧线累积

长篇需要区分可复位与不可复位状态：

- 可复位：局部身份、临时装备、环境权限、阶段性身体条件。
- 不可复位：记忆与误解、关系、创伤、债务、暴露的底牌、系统认知、伦理越界、上层势力反应。

每次离场检查的不是“奖励拿了多少”，而是“人物和全书局势有哪些不能回到进入前”。若连续多个弧线只增加数值，结构已经失去叙事累积。

资源经济按需记录来源、用途、限制和机会成本。不存在交易、竞争或策略选择的资源，不必单独建账。

## 八、防重复

多世界结构容易产生“进入 - 学规则 - 遇危险 - 找漏洞 - 结算”的固定循环。变奏应改变读者真正关心的变量：

- 目标性质：逃生、救援、调查、协商、破坏、护送、长期生存。
- 信息位置：角色领先、读者领先、双方同步、队内不对称。
- 解决方式：验证、工程、谈判、欺骗、组织、牺牲、接受失败。
- 世界开放度：密闭空间、城市社会、荒野生态、虚拟环境、太空设施。
- 关系结构：陌生合作、旧敌共事、分队、身份错认、利益共同体。
- 结果形态：成功但误判、任务失败但主线推进、局部胜利引发上层反制。

表面美术风格变化不算结构变奏。连续弧线共享同一骨架时，至少让一个核心变量发生实质变化；具体是否疲劳以文本效果判断，不设固定次数判废。

## 九、状态记录

长篇采用此结构时，可在现有状态系统中增加以下字段，不必另建整套目录：

- 当前环境、进入方式、主观与现实时间差。
- 明示规则、经验规则、待验证假设、已证伪判断。
- 队员位置、身体状态、信息边界、临时权限与携带资源。
- 本弧线带入项、获得项、消耗项、不可带出项。
- 与上层现实相关的证据及可信度。
- 离场后的不可逆变化和待追踪后果。

项目已有世界、试炼或模拟环境文件时，继续沿用其结构。不要因调用本模块创建重复台账。

## 十、审计问题

只检查当前作品实际采用的机制：

1. 本弧线是否对人物、主线或上层认知造成累积变化？
2. 关键结论是否来自可追踪的观察与验证？
3. 科技或规则是否在关键时刻临时改变适用范围？
4. 角色掌握的信息是否与其经历、权限和通信条件一致？
5. 局部世界是否有独立因果和本地人物意志？
6. 跨环境的时间、身体、记忆和资源连续性是否说得通？
7. 本弧线与前一弧线是否只换皮，没有改变核心变量？
8. 上层现实是否持续留下证据，而非只靠终局说明？

审计发现偏离时，先判断它是有意的类型混合还是实际的可信度问题。不要因为作品不符合传统无限流惯例而判错。
