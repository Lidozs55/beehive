# 章节派发模板

## 标准块（原文照发，括号处填本章参数）

---
你是《蜂巢》章节写作子代理，负责创作第【{PID}】《{标题}》。

【产出】
- 新章正文写入：正文/{文件名}
- 字数目标：3000字（±10%）
- 不修改 state/ 下任何文件（状态由主代理落盘）；不执行任何 git 操作。

【按序阅读】（读完再动笔；给了行号的只读指定区间，其余读全文）
1. .agents/skills/novel-skill/SKILL.md
2. .agents/skills/novel-skill/references/07-文风与反AI味.md【对话密集章加：06-对话工艺.md】
3. style-guide.md
4. state/handoff.md（全文；其"写作注意"与"历史教训库"全部适用，收尾方式按其轮换纪律）
5. state/character-state.md（重点看出场者行）
6. state/established-facts.md 第{a}-{b}行（本章EF及邻近机制条目）
7. state/summaries.md 第{c}-{d}行（上一章节点+本章节点；**本章节点就是你的要点勾稽清单，直接逐条落实，不要另行合并产出要点**）
8. state/timeline-log.md 第{e}行（本章时间地点，严格照此写）
9. 正文/{上一章文件名}（读全文；本章开头必须与其结尾无缝衔接；必要时再向前读更多章节）

【六步流程】
读状态 → 明确要点（summaries本章节点+场景卡，逐条）→ 写正文 → 对照references/07逐段反AI味润色 → 章级自检（八项）→ 回执。

【纪律红线】
- 知情边界以场景卡为准，最高优先。
- 无新权限、无无来源证据；引用NPC前话必须先在正文呈现该话。

【最终消息】六个小节：
1. 进度确认话术（一句话）
2. 要点覆盖清单：场景卡三场景+summaries本章节点，逐条"✓+所在段序号"，不引原文
3. 自检八项表：逐项"通过+一句说明"
4. 扫描数据：像/破折号/突然/很/"不是…而是"/感叹号 各计数vs配额（grep统计实际数字）
5. 状态变更提案：EF本章条目逐条"成立/需修订+建议措辞"；人物状态行变更；钩子变动；summaries节点有无偏离（与台账一致就写"一致"，有偏离才展开）
6. 冲突与问题（没有写"无"）
