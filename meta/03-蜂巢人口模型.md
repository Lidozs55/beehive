| 阶段3平均寿命 | L₃ | **待定** | 按任务评级死亡率估算或暂缓 |

### 关键设定修正

1. **入门试炼"死亡"≠真正死亡**：入门试炼中淘汰（4/6）者仅清除试炼相关记忆，回归正常生活。大脑容量不释放，该个体继续作为普通公民存在。
2. **入门试炼计入10次试炼总数**：1次入门 + 9次普通试炼。
3. **E₃ = E₂（暂作近似，待校准）**：阶段2流出分流为两条路径——虚拟死亡→转入阶段3（不释放容量）、真实死亡→真死（释放容量）。严格式为 E₃ = E₂ × P(先虚拟死亡) < E₂。在缺少阶段2真实死亡率参数前，模型暂保留 E₃ = E₂ 作为近似。
4. **死亡去向矩阵**：阶段1死亡=**直接回收**（意识删除，对外脑死亡，容量释放），C×(1−p) 为**直接计算值**（无复活制修正）；阶段2虚拟死亡=转入阶段3；阶段2真实死亡=真死留尸体。完整矩阵见 `bible/试炼世界/00-试炼总则` §〇。

## 二、稳态公式

### 2.1 容量平衡

大脑容量释放来源（年）：
- 自然死亡：N
- 普通试炼脑死亡（阶段1，通过入门后9次试炼中死亡）：C × (1 − p) = C × 97.4%（阶段1死亡全部释放，无复活制修正项）
  > **注**：phase1 高难任务首次局内死亡=**假死**（预支生命机制——不释放容量、不计入试炼死亡率，人还活着继续 phase1）。上式为不含假死口径的模型简化：假死者仍占用容量且后续仍可能真死/晋级，对稳态总量影响为二阶小量，不单独建模。
- 阶段2真实死亡（真死，释放容量）：E₂ × q（q=阶段2流出中真实死亡占比，**待定参数**，见 §六）
- 阶段3死亡（稳态下=年转入量）：E₃

容量不释放的：
- 入门试炼淘汰：仅清记忆，继续生存
- 阶段2→阶段3转移：意识转入，大脑仍占用（阶段3死亡时才释放）

**稳态方程**（在 E₃=E₂ 近似下）：
```
年容量释放 = N + C×(1−p) + E₃
           = N + C×(1−p) + C×p
           = N + C

年出生 B = 年容量释放 = N + C
```

> **注**：严格式应计入阶段2真实死亡分流——年容量释放 = N + C×(1−p) + E₂×q + E₃，其中 E₃ = E₂×(1−q)（近似，忽略阶段2在队时长）。E₃=E₂ 近似等于假设 q≈0（虚拟死亡先于真实死亡的工蜂占绝大多数）。q 待定后校准。

### 2.2 候选量公式

```
年通过神经元检测人数 = s × B
年通过入门试炼人数（年候选量）C = s × B × (1/3) = s × B / 3
```

联立：
```
B = N + s × B / 3
B × (1 − s/3) = N
B = N / (1 − s/3)
```

### 2.3 各阶段流量

```
年出生/年死亡       B = N / (1 − s/3)
年候选（通过入门）   C = s × B / 3
年入二阶段          E₂ = C × (2/3)^9 = C × 2.6%
年入三阶段（地狱）   E₃ = E₂
地狱稳态人口         P₃ = E₃ × L₃
```

## 四、L₃ 估算框架（已更新·含任务节奏）

任务节奏：1周出勤/3周休整（标准）或1周出勤/1周休整（加速）。各任务时长不一。

### 假设条件

- **标准节奏**：1周出勤 / 3周休整 → ≈13次/年
- **加速节奏**：1周出勤 / 1周休整 → ≈26次/年
- 实际平均可能在两者之间，经验丰富者偏向加速
- 任务评级分布与单次死亡率（**假设值，需校准**）：

| 任务评级 | 分布占比 | 单次个人死亡率 |
| --- | --- | --- |
| 1级 | 50% | 1% |
| 2级 | 25% | 3% |
| 3级 | 15% | 6% |
| 4级 | 7% | 12% |
| 5级 | 3% | 25% |

### 估算

```
单次任务平均死亡率 = 0.5×0.01 + 0.25×0.03 + 0.15×0.06 + 0.07×0.12 + 0.03×0.25 = 3.45%
```

| 节奏 | 年任务次数 | 年死亡率 | L₃ | P₃ |
| --- | --- | --- | --- | --- |
| 标准（1:3） | 13 | 1−(1−0.0345)^13 = 36.4% | 2.7年 | 1,488 |
| 加速（1:1） | 26 | 1−(1−0.0345)^26 = 59.6% | 1.7年 | 937 |
| 标准·低死亡率(2%) | 13 | 23.1% | 4.3年 | 2,369 |
| 标准·极低死亡率(1.5%) | 13 | 17.9% | 5.6年 | 3,086 |
| 标准·极低死亡率(1%) | 13 | 12.2% | 8.2年 | 4,518 |

### 结论

死亡率假设对 L₃ 影响极大。以"数千"地狱人口为目标（P₃ ≈ 2,500–4,500），需要：
- 标准节奏（13次/年）+ 单次平均死亡率 1–1.5%
- 或加速节奏（26次/年）+ 单次平均死亡率 < 0.8%

**建议**：L₃ 暂取 **4–8年**（对应 P₃ ≈ 2,200–4,400），单次平均死亡率约1–1.5%。这意味着大部分任务（1–2级，占75%）的死亡率很低（< 2%），死亡集中在3级以上任务。待任务评级死亡率表的具体数值确定后校准。
